# Orchard design direction

- macOS-familiar layout and interaction patterns
- Orchard-owned branding, artwork, icons, and code
- no Apple logos, Apple icons, Apple artwork, or Apple proprietary code
- Command-style shortcuts mapped to the physical Command / Windows / Search key
- Orchard system menu on the orange top-left mark
- app launcher remains separate from the system menu
- lightweight backend under a consistent Orchard user interface
